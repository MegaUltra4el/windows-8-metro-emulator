# 🪟 Windows 8 Metro UI Emulator

An authentic, fan-made **Windows 8 Metro UI Emulator** built with Electron, HTML, CSS, and JavaScript.

![Version](https://img.shields.io/badge/version-v0.0.0.0001-blue.svg)
![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux-lightgrey.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

---

## ✨ Features

- 🎨 **Authentic Metro Design**: Metro Start Screen animations, tiles, and color palette.
- 🔐 **User Login & Lock Screen**: Interactive login flow inspired by original Windows 8.
- 🌐 **Multi-language Support**: Toggle smoothly between **English** and **Russian**.
- 🔔 **Notifications**: Toast notifications for features in active development.
- 💻 **Cross-Platform**: Ready for Windows (`.exe`) and Linux (`.AppImage` / `.deb`).

---

## 🚀 Download & Run

You can download the latest setup file directly from the [Releases Page](https://github.com/MegaUltra4el/windows-8-metro-emulator/releases).

1. Download `Windows.8.Metro.Emulator.Setup.0.0.0001.exe`
2. Run the installer
3. Enjoy the Metro experience!

## 🛠️ Local Development

If you want to run or build the project from source:

```bash
# Clone the repository
git clone [https://github.com/MegaUltra4el/windows-8-metro-emulator.git](https://github.com/MegaUltra4el/windows-8-metro-emulator.git)

# Navigate into the directory
cd windows-8-metro-emulator

# Install dependencies
npm install

# Run the application
npm start
